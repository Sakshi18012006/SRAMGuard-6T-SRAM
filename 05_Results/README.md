# Results

This folder is reserved for measurements generated from the actual LTspice/SPICE simulation.

## Required result sets
1. Hold SNM
2. Read SNM
3. Write margin/write ability
4. PVT sweep
5. Monte Carlo mismatch distribution
6. Baseline vs optimized sizing comparison

## Rule for final submission
Do not report values that were not generated by the simulation. Store the raw CSV/export where possible and include the simulator settings used to obtain each figure.
