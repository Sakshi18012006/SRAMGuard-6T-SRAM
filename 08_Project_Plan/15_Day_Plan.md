# 15-Day Execution Plan

| Day | Work |
|---|---|
| 1 | Understand 6T topology and install simulator/tools |
| 2 | Draw and verify the transistor-level cell |
| 3 | Verify hold operation |
| 4 | Build read testbench |
| 5 | Build write testbench |
| 6 | Generate butterfly-curve data |
| 7 | Extract/validate hold and read SNM |
| 8 | Measure write margin |
| 9 | Perform VDD sweep |
| 10 | Perform temperature sweep |
| 11 | Add process-corner analysis where models permit |
| 12 | Run mismatch/Monte Carlo analysis where supported |
| 13 | Try transistor sizing optimization |
| 14 | Prepare plots, tables, report and presentation |
| 15 | Final verification, GitHub cleanup and submission ZIP |

## Daily rule
Keep a record of simulator version, model file, supply, temperature, transistor sizes, analysis command and raw output for every reported result.
